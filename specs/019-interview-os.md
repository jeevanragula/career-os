# Spec 019 — Interview OS

## Goal
Turn an application and target role into an evidence-grounded interview preparation workspace.

## Requirements
1. Generate role-specific technical, system design, behavioral, and domain question sets.
2. Use only canonical career claims for suggested stories.
3. Clearly label inferred topics as preparation hypotheses.
4. Track practice sessions and feedback separately from career evidence.
5. Never convert generated practice answers into verified career claims automatically.

## Acceptance criteria
- Every suggested experience story maps to claims.
- Practice notes remain separate from canonical evidence.
- Preparation can be regenerated for a new job version.
