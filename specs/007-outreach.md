# Specification 007 — Personalized Outreach

- Status: Draft
- Version: 0.1
- Milestone: M7

## Purpose

Generate concise, role-specific outreach to recruiters, hiring managers, founders, CTOs, and relevant engineering leaders.

## Principles

Personalization is evidence-based. Claims come from Career Brain. Researched facts retain source context. Sending always requires human approval.

## Acceptance criteria

- [ ] Recipient relevance is recorded.
- [ ] Personalization facts have source references.
- [ ] Message claims trace to career evidence.
- [ ] Sending requires explicit approval.
- [ ] Sent messages and responses can be tracked.
