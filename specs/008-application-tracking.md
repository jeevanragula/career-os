# Specification 008 — Application Tracking

- Status: Draft
- Version: 0.1
- Milestone: M6

## Purpose

Maintain a durable timeline for opportunities, applications, contacts, interviews, and outcomes.

## Events

discovered, analyzed, shortlisted, application prepared, application submitted, recruiter contacted, recruiter response, interview scheduled, interview completed, follow-up, rejection, offer, withdrawal.

## Acceptance criteria

- [ ] Every application has a timeline.
- [ ] Events have timestamps and sources where applicable.
- [ ] External actions link to approval records.
- [ ] Follow-ups can be scheduled from application state.
